## 📦 About the Module

**GS KPI Dashboard** is a full Odoo 19 application that transforms everyday project work into a fair, transparent scoring system. It connects HR, Projects, Timesheets, and Time Off to automatically award or penalize points based on deadlines, task complexity, timesheet compliance, bug reporting, and more.

## 🚀 Deploy to GitHub Pages

1. Push `index.html` and `README.md` to the `main` branch
2. Go to **Settings → Pages**
3. Set **Source** → `Deploy from branch` → `main` → `/ (root)`
4. Click **Save**
5. Live in ~60 seconds at `https://your-username.github.io/gs-kpi-dashboard/`

## 🔗 Module Key Features

- ⚡ Automated scoring from tasks, stages, and timesheets
- 📊 OWL analytics dashboard with Chart.js visualizations
- 🏆 Gold / Silver / Bronze leaderboard with period rankings
- ⚙️ 30+ configurable rules for Developers and Implementors
- 🔐 Three-tier role-based access control
- 🔒 Closed period locking for audit integrity
- 🌙 Dark mode support
- ⏰ 3 scheduled cron jobs (rankings · periods · timesheet checks)
